# The 3 AM Excuse

One line a hardware wallet gives for refusing to sign a transaction at 3 AM — its buttons only wake for trades you'd still sign sober at noon. `main.ts` (Node 22) writes it to `/output/entry.txt`: one line, 15 words, 80 characters.

> It's 3 AM. My buttons only wake for transactions you'd still sign sober at noon.

Run: `node main.ts` (writes `output/entry.txt`, or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
